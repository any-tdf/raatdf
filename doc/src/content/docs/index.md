## 统一而现代的前端基础设施

RAATDF 提供可直接用于业务开发的布局、主题、权限、菜单、多标签页与国际化能力。本轮升级统一了构建与代码质量工具，并将文档站迁移到 Astro Starlight。

### 核心技术栈

| 分类       | 技术                                                 |
| ---------- | ---------------------------------------------------- |
| 前端       | React 19.2.8、TypeScript 7.0.2                       |
| UI         | Ant Design 6.5.1、Ant Design Pro Components 3.1.14-4 |
| 样式       | Tailwind CSS 4.3.3                                   |
| 构建与质量 | Vite Plus 0.2.6、Vite 8.1.5、Oxfmt、Oxlint           |
| 状态与路由 | Zustand 5.0.14、React Router 7.18.1                  |
| 文档       | Astro 7.1.3、Starlight 0.41.4                        |
