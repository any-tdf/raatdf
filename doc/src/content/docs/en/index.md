## A unified, modern frontend foundation

RAATDF provides production-ready layouts, themes, permissions, menus, multi-tab navigation, and internationalization. This upgrade unifies the build and code-quality toolchain and moves the documentation site to Astro Starlight.

### Core stack

| Category          | Technology                                           |
| ----------------- | ---------------------------------------------------- |
| Frontend          | React 19.2.8, TypeScript 7.0.2                       |
| UI                | Ant Design 6.5.1, Ant Design Pro Components 3.1.14-4 |
| Styling           | Tailwind CSS 4.3.3                                   |
| Build and quality | Vite Plus 0.2.6, Vite 8.1.5, Oxfmt, Oxlint           |
| State and routing | Zustand 5.0.14, React Router 7.18.1                  |
| Documentation     | Astro 7.1.3, Starlight 0.41.4                        |
