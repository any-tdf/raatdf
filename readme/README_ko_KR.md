# 프로젝트 개요

RAATDF는 최신 기술 스택으로 구축된 효율적이고 우아하며 가벼운 엔터프라이즈 관리 템플릿으로, 즉시 사용 가능한 솔루션을 제공합니다.

# 빠른 링크

📺 [온라인 데모](https://raatdf.com) | 📖 [문서](https://doc.raatdf.com) | 🐙 [GitHub 저장소](https://github.com/any-tdf/raatdf)

# 핵심 기술 스택

- **빌드 도구**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - 초고속 개발 경험
- **프론트엔드 프레임워크**: [React](https://react.dev) v19 - 최신 버전, React Compiler 지원
- **타입 시스템**: [TypeScript](https://www.typescriptlang.org) v7 - 엄격한 타입 검사
- **UI 프레임워크**: [Ant Design](https://ant.design) v6 - 엔터프라이즈 UI 컴포넌트 라이브러리
- **스타일링**: [Tailwind CSS](https://tailwindcss.com) v4 - 원자화 CSS 프레임워크
- **상태 관리**: [Zustand](https://zustand-demo.pmnd.rs) v5 - 가벼운 상태 관리
- **라우팅**: [React Router](https://reactrouter.com) v7 - 최신 라우팅 솔루션
- **코드 품질**: [Vite+](https://viteplus.dev) - 통합된 코드 검사 및 포맷팅 도구

# 기능 특성

## 레이아웃 시스템

- **다양한 레이아웃**: 사이드바, 상단 바, 혼합 레이아웃
- **반응형 디자인**: 모든 화면 크기에 완벽한 호환
- **플로팅 UI**: 우아한 플로팅 UI 스타일
- **몰입 모드**: 콘텐츠에 집중하는 전체 화면 경험
- **사이드 도구**: 도구 모음을 사이드바 하단에 배치(수직 레이아웃만 해당)

## 테마 시스템

- **라이트/다크 테마**: 라이트, 다크, 시스템 따라가기 세 가지 모드
- **테마 색상**: 10개 이상의 프리셋 색상 + 커스텀 색상
- **동적 전환**: CSS 변수를 통한 원활한 테마 전환
- **테두리 반경 크기**: 9가지 테두리 반경 크기(0-24px) 선택 가능

## 상호작용 향상

- **멀티 탭**: 최대 16개 탭, 자동으로 가장 오래된 탭 닫기
- **페이지 캐싱**: 페이지 상태 유지로 사용자 경험 향상
- **탭 스타일**: 기본, 버튼, 간결, 스택의 4가지 스타일
- **전환 애니메이션**: 슬라이드, 페이드인, 스케일 등 다양한 애니메이션 효과
- **컴팩트 모드**: 데이터 집약적인 시나리오에 적합

## 표시 옵션

- **페이지 너비**: 적응형 또는 고정 너비
- **카드 컨테이너**: 카드 스타일 콘텐츠 표시
- **새로고침 버튼**: 페이지 빠른 새로고침
- **접기 버튼**: 사이드바 확장/접기 전환
- **상단 바 버튼**: 알림 센터, 채팅 창 등

## 국제화

- **다국어**: 중국어, 영어 내장, 확장 용이
- **완전한 번역**: 시스템 설정, 메뉴, 알림 등
- **동적 전환**: 페이지 새로고침 없이 언어 전환

# 빠른 시작

## 환경 요구 사항

- Node.js ^22.18.0 또는 >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## 설치 및 사용

```bash
# 저장소 복제
git clone git@github.com:any-tdf/raatdf.git

# 프로젝트 디렉터리로 이동
cd raatdf

# 의존성 설치
bun install

# 개발 서버 시작
bun run dev

# 프로덕션 빌드
bun run build

# 프로덕션 빌드 미리보기
bun run preview
```

## 자주 사용하는 명령어

```bash
# 코드 검사 및 포맷팅
bun run check  # Vite+ 검사 실행
bun run check:fix  # 코드 문제 자동 수정
bun run lint  # 코드 규범만 검사
bun run lint:fix  # 코드 규범 문제 자동 수정
bun run format  # 코드 포맷 검사
bun run format:fix  # 코드 자동 포맷팅
```

# 기여

새 기능, 버그 수정, 문서 개선 등 모든 형태의 기여를 환영합니다.

## 기여 방법

1. 이 저장소 포크
2. 기능 브랜치 생성 (`git checkout -b feature/AmazingFeature`)
3. 변경 사항 커밋 (`git commit -m 'feat: add some amazing feature'`)
4. 브랜치에 푸시 (`git push origin feature/AmazingFeature`)
5. Pull Request 열기

## 커밋 규범

[Conventional Commits](https://www.conventionalcommits.org/ko/v1.0.0/)를 따라주세요:

- `feat`: 새 기능
- `fix`: 버그 수정
- `docs`: 문서 업데이트
- `style`: 코드 포맷 변경
- `refactor`: 코드 리팩토링
- `chore`: 빌드 도구 또는 보조 도구 변경
