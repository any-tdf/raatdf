# Projektübersicht

RAATDF ist ein effizientes, elegantes und leichtgewichtiges Unternehmens-Admin-Template, das mit den neuesten Technologien gebaut wurde und einsatzbereite Lösungen bietet.

# Quick Links

📺 [Online Demo](https://raatdf.com) | 📖 [Dokumentation](https://doc.raatdf.com) | 🐙 [GitHub Repository](https://github.com/any-tdf/raatdf)

# Haupt-Technologie-Stack

- **Build-Tool**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - Ultra-schnelle Entwicklungserfahrung
- **Frontend-Framework**: [React](https://react.dev) v19 - Neueste Version mit React Compiler Support
- **Typsystem**: [TypeScript](https://www.typescriptlang.org) v7 - Strikte Typprüfung
- **UI-Framework**: [Ant Design](https://ant.design) v6 - Unternehmens-UI-Komponentenbibliothek
- **Styling**: [Tailwind CSS](https://tailwindcss.com) v4 - Atomares CSS-Framework
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs) v5 - Leichtgewichtiges State Management
- **Routing**: [React Router](https://reactrouter.com) v7 - Neueste Routing-Lösung
- **Code-Qualität**: [Vite+](https://viteplus.dev) - Einheitliches Code-Check- und Formatierungstool

# Features

## Layout-System

- **Mehrere Layouts**: Seitenleiste, oberste Leiste, gemischtes Layout
- **Responsives Design**: Perfekte Kompatibilität mit allen Bildschirmgrößen
- **Floating UI**: Eleganter Floating-UI-Stil
- **Immersiver Modus**: Vollbildeffahrung, fokussiert auf Inhalte
- **Seitenwerkzeuge**: Platzierung der Werkzeugleiste am unteren Ende der Seitenleiste (nur vertikales Layout)

## Theme-System

- **Hell/Dunkel Theme**: Drei Modi - hell, dunkel, System folgen
- **Theme-Farben**: 10+ voreingestellte Farben + benutzerdefinierte Farben
- **Dynamischer Wechsel**: Nahtloser Theme-Wechsel über CSS-Variablen
- **Rundungsgröße**: 9 wählbare Rundungsgrößen (0-24px)

## Interaktionsverbesserungen

- **Multi-Tabs**: Bis zu 16 Tabs, automatisch ältesten Tab schließen
- **Seiten-Cache**: Seitenzustand beibehalten, Benutzererfahrung verbessern
- **Tab-Stile**: 4 Stile - Standard, Button, Simple, Stack
- **Übergangsanimationen**: Vielfältige Animationseffekte wie Slide, FadeIn, Scale
- **Kompakter Modus**: Geeignet für datenintensive Szenarien

## Anzeigeoptionen

- **Seitenbreite**: Adaptiv oder feste Breite
- **Karten-Container**: Kartenstil-Inhaltsanzeige
- **Aktualisierungs-Button**: Schnelle Seitenaktualisierung
- **Einklapp-Button**: Seitenleiste-Erweiterung/-einklappung umschalten
- **Obere Leiste-Buttons**: Benachrichtigungszentrum, Chat-Fenster etc.

## Internationalisierung

- **Mehrsprachig**: Integriertes Chinesisch und Englisch, einfach erweiterbar
- **Vollständige Übersetzung**: Systemeinstellungen, Menüs, Benachrichtigungen etc.
- **Dynamischer Wechsel**: Sprachwechsel ohne Seitenaktualisierung

# Schnellstart

## Umgebungsanforderungen

- Node.js ^22.18.0 oder >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## Installation und Verwendung

```bash
# Repository klonen
git clone git@github.com:any-tdf/raatdf.git

# In Projektverzeichnis wechseln
cd raatdf

# Abhängigkeiten installieren
bun install

# Entwicklungsserver starten
bun run dev

# Für Produktion bauen
bun run build

# Produktions-Build-Vorschau
bun run preview
```

## Häufige Befehle

```bash
# Code-Check und Formatierung
bun run check  # Vite+-Check ausführen
bun run check:fix  # Code-Probleme automatisch korrigieren
bun run lint  # Nur Code-Standards prüfen
bun run lint:fix  # Code-Standard-Probleme automatisch korrigieren
bun run format  # Code-Format prüfen
bun run format:fix  # Code automatisch formatieren
```
