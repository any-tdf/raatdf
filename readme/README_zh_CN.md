# 项目概述

RAATDF 是一个高效、优雅、轻量级的企业级后台管理模板，采用最新技术栈构建，提供开箱即用的解决方案。

# 快速链接

📺 [在线演示](https://raatdf.com) | 📖 [使用文档](https://doc.raatdf.com) | 🐙 [GitHub 仓库](https://github.com/any-tdf/raatdf)

# 核心技术栈

- **构建工具**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - 极速开发体验
- **前端框架**: [React](https://react.dev) v19 - 最新版本，支持 React Compiler
- **类型系统**: [TypeScript](https://www.typescriptlang.org) v7 - 严格类型检查
- **UI 框架**: [Ant Design](https://ant.design) v6 - 企业级 UI 组件库
- **样式方案**: [Tailwind CSS](https://tailwindcss.com) v4 - 原子化 CSS 框架
- **状态管理**: [Zustand](https://zustand-demo.pmnd.rs) v5 - 轻量级状态管理
- **路由方案**: [React Router](https://reactrouter.com) v7 - 最新路由解决方案
- **代码质量**: [Vite+](https://viteplus.dev) - 统一的代码检查和格式化工具
- **文档站**：[Astro](https://astro.build) v7 + [Starlight](https://starlight.astro.build) v0.41

# 功能特性

## 布局系统

- **多种布局**: 侧边栏、顶栏、混合布局
- **响应式设计**: 完美适配所有屏幕尺寸
- **浮动 UI**: 优雅的浮动 UI 风格
- **沉浸模式**: 专注内容的全屏体验
- **侧栏工具**: 将工具栏放置在侧边栏底部（仅垂直布局）

## 主题系统

- **明暗主题**: 亮色、暗色、跟随系统三种模式
- **主题色**: 10+ 预设颜色 + 自定义颜色
- **动态切换**: 通过 CSS 变量实现无缝主题切换
- **圆角大小**: 9 种圆角尺寸可选（0-24px）

## 交互增强

- **多标签页**: 最多 16 个标签页，自动关闭最早标签
- **页面缓存**: 保留页面状态，提升用户体验
- **标签风格**: 默认、按钮、简洁、堆叠四种风格
- **过渡动画**: 滑动、淡入、缩放等多种动画效果
- **紧凑模式**: 适合数据密集型场景

## 显示选项

- **页面宽度**: 自适应或固定宽度
- **卡片容器**: 卡片式内容展示
- **刷新按钮**: 快速刷新页面
- **折叠按钮**: 切换侧边栏展开/收起
- **顶栏按钮**: 通知中心、聊天窗口等

## 国际化

- **多语言**: 内置中英文，易于扩展
- **完整翻译**: 系统设置、菜单、提示等
- **动态切换**: 无需刷新页面即可切换语言

# 快速开始

## 环境要求

- Node.js ^22.18.0 或 >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## 安装使用

```bash
# 克隆仓库
git clone git@github.com:any-tdf/raatdf.git

# 进入项目目录
cd raatdf

# 安装依赖
bun install

# 启动开发服务器
bun run dev

# 构建生产版本
bun run build

# 预览生产版本
bun run preview
```

## 常用命令

```bash
# 代码检查和格式化
bun run check  # 运行 Vite+ 检查
bun run check:fix  # 自动修复代码问题
bun run lint  # 仅检查代码规范
bun run lint:fix  # 自动修复代码规范问题
bun run format  # 检查代码格式
bun run format:fix  # 自动格式化代码
```

## 文档站命令

```bash
cd doc
bun install
bun run dev  # 启动 Astro Starlight 文档站
bun run check  # 执行 Astro 类型检查、Oxfmt 和 Oxlint
bun run build  # 构建文档站
```

依赖、工具链和路由变化请参阅 [0.2.0 升级说明](https://doc.raatdf.com/upgrade/)。

我们欢迎所有形式的贡献，无论是新功能、错误修复还是文档改进。

## 如何贡献

1. Fork 本仓库
2. 创建您的特性分支 (`git checkout -b feature/AmazingFeature`)
3. 提交您的更改 (`git commit -m 'feat: add some amazing feature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 打开一个 Pull Request

## 提交规范

请遵循 [约定式提交](https://www.conventionalcommits.org/zh-hans/)：

- `feat`: 新功能

- `docs`: 文档更新
