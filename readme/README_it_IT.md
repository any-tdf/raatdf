# Riepilogo del Progetto

RAATDF è un template di amministrazione aziendale efficiente, elegante e leggero, costruito con le tecnologie più recenti, fornendo soluzioni pronte all'uso.

# Link Rapidi

📺 [Demo Online](https://raatdf.com) | 📖 [Documentazione](https://doc.raatdf.com) | 🐙 [Repository GitHub](https://github.com/any-tdf/raatdf)

# Stack Tecnologico Principale

- **Strumento di Build**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - Esperienza di sviluppo ultraveloce
- **Framework Frontend**: [React](https://react.dev) v19 - Ultima versione con supporto per React Compiler
- **Sistema di Tipi**: [TypeScript](https://www.typescriptlang.org) v7 - Controllo tipi rigoroso
- **Framework UI**: [Ant Design](https://ant.design) v6 - Libreria di componenti UI aziendali
- **Styling**: [Tailwind CSS](https://tailwindcss.com) v4 - Framework CSS atomico
- **Gestione Stato**: [Zustand](https://zustand-demo.pmnd.rs) v5 - Gestione stato leggera
- **Routing**: [React Router](https://reactrouter.com) v7 - Soluzione di routing più recente
- **Qualità Codice**: [Vite+](https://viteplus.dev) - Strumento unificato di controllo e formattazione codice

# Funzionalità

## Sistema di Layout

- **Layout Multipli**: Barra laterale, barra superiore, layout misto
- **Design Responsive**: Compatibilità perfetta con tutte le dimensioni dello schermo
- **UI Fluttuante**: Stile UI fluttuante elegante
- **Modalità Immersiva**: Esperienza a schermo intero focalizzata sul contenuto
- **Strumenti Laterali**: Posizionare la barra degli strumenti in basso alla barra laterale (solo layout verticale)

## Sistema di Temi

- **Tema Chiaro/Scuro**: Tre modalità - chiaro, scuro, segue il sistema
- **Colori del Tema**: 10+ colori predefiniti + colori personalizzati
- **Cambio Dinamico**: Transizione tema fluida tramite variabili CSS
- **Dimensione Bordo Arrotondato**: 9 dimensioni bordo arrotondato selezionabili (0-24px)

## Miglioramenti Interazione

- **Multi-Schede**: Fino a 16 schede, chiudi automaticamente la più vecchia
- **Cache Pagine**: Mantenere stato pagina, migliorare esperienza utente
- **Stili Schede**: 4 stili - predefinito, pulsante, semplice, stack
- **Animazioni Transizione: Effetti animazione variati come slide, fadeIn, scale
- **Modalità Compatta**: Adatta a scenari intensivi di dati

## Opzioni Visualizzazione

- **Larghezza Pagina**: Adattiva o fissa
- **Contenitore Schede**: Visualizzazione contenuto stile scheda
- **Pulsante Aggiorna**: Rapido aggiornamento pagina
- **Pulsante Comprimi**: Alterna espansione/compressione barra laterale
- **Pulsanti Barra Superiore**: Centro notifiche, finestra chat, ecc.

## Internazionalizzazione

- **Multilingua**: Cinese e inglese integrati, facile da estendere
- **Traduzione Completa**: Impostazioni di sistema, menu, notifiche, ecc.
- **Cambio Dinamico**: Cambia lingua senza ricaricare la pagina

# Avvio Rapido

## Requisiti Ambiente

- Node.js ^22.18.0 o >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## Installazione e Utilizzo

```bash
# Clona il repository
git clone git@github.com:any-tdf/raatdf.git

# Entra nella directory del progetto
cd raatdf

# Installa le dipendenze
bun install

# Avvia il server di sviluppo
bun run dev

# Costruisci per la produzione
bun run build

# Anteprima build di produzione
bun run preview
```

## Comandi Comuni

```bash
# Controllo e formattazione del codice
bun run check  # Esegui controllo Vite+
bun run check:fix  # Correggi automaticamente problemi codice
bun run lint  # Controlla solo standard codice
bun run lint:fix  # Correggi automaticamente problemi standard codice
bun run format  # Controlla formato codice
bun run format:fix  # Formatta automaticamente il codice
```

# Contribuire

Accogliamo tutte le forme di contributo, siano esse nuove funzionalità, correzioni di bug o miglioramenti della documentazione.

## Come Contribuire

1. Fork questo repository
2. Crea il tuo ramo di funzionalità (`git checkout -b feature/AmazingFeature`)
3. Esegui il commit delle tue modifiche (`git commit -m 'feat: add some amazing feature'`)
4. Push al ramo (`git push origin feature/AmazingFeature`)
5. Apri una Pull Request

## Convenzione di Commit

Si prega di seguire [Conventional Commits](https://www.conventionalcommits.org/it/v1.0.0/):

- `feat`: nuova funzionalità
- `fix`: correzione bug
- `docs`: aggiornamento documentazione
- `style`: modifica formato codice
- `refactor`: refactoring codice
- `chore`: modifica strumenti di build o strumenti ausiliari
