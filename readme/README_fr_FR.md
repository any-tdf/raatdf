# Résumé du Projet

RAATDF est un modèle d'administration d'entreprise efficace, élégant et léger, construit avec les technologies les plus récentes, fournissant des solutions prêtes à l'emploi.

# Liens Rapides

📺 [Démo en ligne](https://raatdf.com) | 📖 [Documentation](https://doc.raatdf.com) | 🐙 [Dépôt GitHub](https://github.com/any-tdf/raatdf)

# Pile Technologique Principale

- **Outil de Build**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - Expérience de développement ultra-rapide
- **Framework Frontend**: [React](https://react.dev) v19 - Dernière version, support pour React Compiler
- **Système de Types**: [TypeScript](https://www.typescriptlang.org) v7 - Vérification de types stricte
- **Framework UI**: [Ant Design](https://ant.design) v6 - Bibliothèque de composants UI d'entreprise
- **Stylisme**: [Tailwind CSS](https://tailwindcss.com) v4 - Framework CSS atomique
- **Gestion d'État**: [Zustand](https://zustand-demo.pmnd.rs) v5 - Gestion d'état légère
- **Routage**: [React Router](https://reactrouter.com) v7 - Solution de routage la plus récente
- **Qualité de Code**: [Vite+](https://viteplus.dev) - Outil unifié de vérification et formatage de code

# Caractéristiques

## Système de Layout

- **Multiples Layouts**: Barre latérale, barre supérieure, layout mixte
- **Design Responsive**: Compatibilité parfaite avec toutes les tailles d'écran
- **UI Flottant**: Style UI flottant élégant
- **Mode Immersif**: Expérience plein écran centrée sur le contenu
- **Outils Latéraux**: Placer la barre d'outils en bas de la barre latérale (layout vertical uniquement)

## Système de Thèmes

- **Thème Clair/Sombre**: Trois modes - clair, sombre, suivre le système
- **Couleurs de Thème**: 10+ couleurs prédéfinies + couleurs personnalisées
- **Changement Dynamique**: Transition de thème fluide via variables CSS
- **Taille de Bordure Arrondie**: 9 tailles de bordure arrondie sélectionnables (0-24px)

## Améliorations d'Interaction

- **Multi-onglets**: Maximum 16 onglets, fermer automatiquement le plus ancien
- **Cache de Pages**: Maintenir l'état de la page, améliorer l'expérience utilisateur
- **Styles d'Onglets**: 4 styles - défaut, bouton, simple, pile
- **Animations de Transition**: Effets d'animation variés comme slide, fadeIn, scale
- **Mode Compact**: Convient aux scénarios intensifs en données

## Options d'Affichage

- **Largeur de Page**: Adaptative ou fixe
- **Conteneur de Cartes**: Affichage de contenu style carte
- **Bouton d'Actualisation**: Actualisation rapide de page
- **Bouton de Réduction**: Basculer l'expansion/réduction de la barre latérale
- **Boutons de Barre Supérieure**: Centre de notifications, fenêtre de chat, etc.

## Internationalisation

- **Multilingue**: Chinois et anglais intégrés, facile à étendre
- **Traduction Complète**: Paramètres système, menus, notifications, etc.
- **Changement Dynamique**: Changer de langue sans recharger la page

# Démarrage Rapide

## Exigences d'Environnement

- Node.js ^22.18.0 ou >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## Installation et Utilisation

```bash
# Cloner le dépôt
git clone git@github.com:any-tdf/raatdf.git

# Entrer dans le répertoire du projet
cd raatdf

# Installer les dépendances
bun install

# Démarrer le serveur de développement
bun run dev

# Construire pour la production
bun run build

# Prévisualiser la build de production
bun run preview
```

## Commandes Courantes

```bash
# Vérification et formatage de code
bun run check  # Exécuter la vérification Vite+
bun run check:fix  # Corriger automatiquement les problèmes de code
bun run lint  # Vérifier uniquement les normes de code
bun run lint:fix  # Corriger automatiquement les problèmes de normes de code
bun run format  # Vérifier le formatage du code
bun run format:fix  # Formater automatiquement le code
```

# Contribuer

Nous accueillons toutes les formes de contribution, qu'il s'agisse de nouvelles fonctionnalités, de corrections de bugs ou d'améliorations de documentation.

## Comment Contribuer

1. Fork ce dépôt
2. Créer votre branche de fonctionnalité (`git checkout -b feature/AmazingFeature`)
3. Committez vos modifications (`git commit -m 'feat: add some amazing feature'`)
4. Pushez vers la branche (`git push origin feature/AmazingFeature`)
5. Ouvrez une Pull Request

## Convention de Commit

Veuillez suivre [Conventional Commits](https://www.conventionalcommits.org/fr/v1.0.0/) :

- `feat`: nouvelle fonctionnalité
- `fix`: correction de bug
- `docs`: mise à jour de documentation
- `style`: changement de format de code
- `refactor`: refactoring de code
- `chore`: changement dans les outils de build ou outils auxiliaires
