# プロジェクト概要

RAATDF は、最新技術スタックで構築された、効率的でエレガント、軽量なエンタープライズ管理テンプレートであり、すぐに使えるソリューションを提供します。

# クイックリンク

📺 [オンラインデモ](https://raatdf.com) | 📖 [ドキュメント](https://doc.raatdf.com) | 🐙 [GitHub リポジトリ](https://github.com/any-tdf/raatdf)

# コア技術スタック

- **ビルドツール**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - 超高速開発体験
- **フロントエンドフレームワーク**: [React](https://react.dev) v19 - 最新版、React Compiler をサポート
- **型システム**: [TypeScript](https://www.typescriptlang.org) v7 - 厳格な型チェック
- **UI フレームワーク**: [Ant Design](https://ant.design) v6 - エンタープライズ UI コンポーネントライブラリ
- **スタイリング**: [Tailwind CSS](https://tailwindcss.com) v4 - 原子化 CSS フレームワーク
- **状態管理**: [Zustand](https://zustand-demo.pmnd.rs) v5 - 軽量ステート管理
- **ルーティング**: [React Router](https://reactrouter.com) v7 - 最新ルーティングソリューション
- **コード品質**: [Vite+](https://viteplus.dev) - 統一されたコードチェックとフォーマットツール

# 機能特性

## レイアウトシステム

- **多様なレイアウト**: サイドバー、トップバー、混合レイアウト
- **レスポンシブデザイン**: すべての画面サイズに完全対応
- **フローティング UI**: エレガントなフローティング UI スタイル
- **没入モード**: コンテンツに集中するフルスクリーン体験
- **サイドツール**: ツールバーをサイドバー下部に配置（垂直レイアウトのみ）

## テーマシステム

- **明暗テーマ**: ライト、ダーク、システム追従の 3 つのモード
- **テーマカラー**: 10+ プリセットカラー + カスタムカラー
- **動的切り替え**: CSS 変数でシームレスなテーマ切り替え
- **角丸サイズ**: 9 種類の角丸サイズ（0-24px）選択可能

## インタラクション強化

- **マルチタブ**: 最大 16 タブ、自動で最も古いタブを閉じる
- **ページキャッシュ**: ページ状態を保持し、ユーザー体験を向上
- **タブスタイル**: デフォルト、ボタン、シンプル、スタックの 4 種類
- **トランジションアニメーション**: スライド、フェードイン、スケールなど多彩なアニメーション効果
- **コンパクトモード**: データ集約型シーンに適した

## 表示オプション

- **ページ幅**: アダプティブまたは固定幅
- **カードコンテナ**: カードスタイルコンテンツ表示
- **更新ボタン**: ページのクイック更新
- **折りたたみボタン**: サイドバーの展開/折りたたみ切り替え
- **トップバーボタン**: 通知センター、チャットウィンドウなど

## 国際化

- **多言語**: 中国語・英語を内蔵、拡張容易
- **完全翻訳**: システム設定、メニュー、ヒントなど
- **動的切り替え**: ページ更新なしで言語切り替え

# クイックスタート

## 環境要件

- Node.js ^22.18.0 または >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## インストールと使用

```bash
# リポジトリをクローン
git clone git@github.com:any-tdf/raatdf.git

# プロジェクトディレクトリに移動
cd raatdf

# 依存関係をインストール
bun install

# 開発サーバーを起動
bun run dev

# 本番用にビルド
bun run build

# 本番用ビルドをプレビュー
bun run preview
```

## よく使うコマンド

```bash
# コードチェックとフォーマット
bun run check  # Vite+ チェックを実行
bun run check:fix  # コード問題を自動修正
bun run lint  # コード規範のみチェック
bun run lint:fix  # コード規範問題を自動修正
bun run format  # コードフォーマットチェック
bun run format:fix  # コードを自動フォーマット
```
