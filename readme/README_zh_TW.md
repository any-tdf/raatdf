# 專案概述

RAATDF 是一個高效、優雅、輕量級的企業級後台管理模板，採用最新技術棧構建，提供開箱即用的解決方案。

# 快速連結

📺 [線上演示](https://raatdf.com) | 📖 [使用文件](https://doc.raatdf.com) | 🐙 [GitHub 倉庫](https://github.com/any-tdf/raatdf)

# 核心技術棧

- **建構工具**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - 極速開發體驗
- **前端框架**: [React](https://react.dev) v19 - 最新版本，支援 React Compiler
- **類型系統**: [TypeScript](https://www.typescriptlang.org) v7 - 嚴格類型檢查
- **UI 框架**: [Ant Design](https://ant.design) v6 - 企業級 UI 元件庫
- **樣式方案**: [Tailwind CSS](https://tailwindcss.com) v4 - 原子化 CSS 框架
- **狀態管理**: [Zustand](https://zustand-demo.pmnd.rs) v5 - 輕量級狀態管理
- **路由方案**: [React Router](https://reactrouter.com) v7 - 最新路由解決方案
- **程式碼品質**: [Vite+](https://viteplus.dev) - 統一的程式碼檢查和格式化工具

# 功能特性

## 佈局系統

- **多種佈局**: 側邊欄、頂欄、混合佈局
- **響應式設計**: 完美適配所有螢幕尺寸
- **浮動 UI**: 優雅的浮動 UI 風格
- **沉浸模式**: 專注內容的全螢幕體驗
- **側欄工具**: 將工具列放置在側邊欄底部（僅垂直佈局）

## 主題系統

- **明暗主題**: 亮色、暗色、跟隨系統三種模式
- **主題色**: 10+ 預設顏色 + 自訂顏色
- **動態切換**: 透過 CSS 變數實現無縫主題切換
- **圓角大小**: 9 種圓角尺寸可選（0-24px）

## 互動增強

- **多標籤頁**: 最多 16 個標籤頁，自動關閉最早標籤
- **頁面快取**: 保留頁面狀態，提升使用者體驗
- **標籤風格**: 預設、按鈕、簡潔、堆疊四種風格
- **過渡動畫**: 滑動、淡入、縮放等多種動畫效果
- **緊湊模式**: 適合資料密集型場景

## 顯示選項

- **頁面寬度**: 自適應或固定寬度
- **卡片容器**: 卡片式內容展示
- **重新整理按鈕**: 快速重新整理頁面
- **摺疊按鈕**: 切換側邊欄展開/收起
- **頂欄按鈕**: 通知中心、聊天視窗等

## 國際化

- **多語言**: 內建中英文，易於擴展
- **完整翻譯**: 系統設定、選單、提示等
- **動態切換**: 無需重新整理頁面即可切換語言

# 快速開始

## 環境要求

- Node.js ^22.18.0 或 >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## 安裝使用

```bash
# 複製倉庫
git clone git@github.com:any-tdf/raatdf.git

# 進入專案目錄
cd raatdf

# 安裝依賴
bun install

# 啟動開發伺服器
bun run dev

# 建構生產版本
bun run build

# 預覽生產版本
bun run preview
```

## 常用指令

```bash
# 程式碼檢查和格式化
bun run check  # 執行 Vite+ 檢查
bun run check:fix  # 自動修復程式碼問題
bun run lint  # 僅檢查程式碼規範
bun run lint:fix  # 自動修復程式碼規範問題
bun run format  # 檢查程式碼格式
bun run format:fix  # 自動格式化程式碼
```
