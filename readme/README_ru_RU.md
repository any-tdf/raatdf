# Обзор проекта

RAATDF - это эффективный, элегантный и легковесный шаблон административной панели для предприятий, построенный на основе новейших технологий и готовый к использованию.

# Быстрые ссылки

📺 [Онлайн демо](https://raatdf.com) | 📖 [Документация](https://doc.raatdf.com) | 🐙 [Репозиторий GitHub](https://github.com/any-tdf/raatdf)

# Основной стек технологий

- **Сборка**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - сверхбыстрая разработка
- **Фронтенд фреймворк**: [React](https://react.dev) v19 - последняя версия с поддержкой React Compiler
- **Система типов**: [TypeScript](https://www.typescriptlang.org) v7 - строгая типизация
- **UI фреймворк**: [Ant Design](https://ant.design) v6 - библиотека компонентов для предприятия
- **Стили**: [Tailwind CSS](https://tailwindcss.com) v4 - атомарный CSS фреймворк
- **Управление состоянием**: [Zustand](https://zustand-demo.pmnd.rs) v5 - легковесное управление состоянием
- **Маршрутизация**: [React Router](https://reactrouter.com) v7 - новейшее решение маршрутизации
- **Качество кода**: [Vite+](https://viteplus.dev) - унифицированный инструмент проверки и форматирования кода

# Функциональные возможности

## Система компоновки

- **Множественные макеты**: боковая панель, верхняя панель, смешанный макет
- **Адаптивный дизайн**: полная совместимость со всеми размерами экрана
- **Плавающий UI**: элегантный стиль плавающего интерфейса
- **Режим погружения**: полноэкранный опыт, сфокусированный на контенте
- **Боковые инструменты**: размещение панели инструментов внизу боковой панели (только вертикальная компоновка)

## Система тем

- **Светлая/тёмная тема**: три режима - светлая, тёмная, как в системе
- **Цвета темы**: 10+ предустановленных цветов + пользовательские цвета
- **Динамическое переключение**: бесшовное переключение тем через CSS-переменные
- **Размер скругления углов**: 9 selectable размеров скругления углов (0-24px)

## Улучшения взаимодействия

- **Многооконность**: до 16 вкладок, автоматическое закрытие самой старой
- **Кэширование страниц**: сохранение состояния страниц, улучшение пользовательского опыта
- **Стили вкладок**: 4 стиля - стандартный, кнопка, простой, стек
- **Анимации переходов**: разнообразные эффекты анимации - слайд, fadeIn, масштаб
- **Компактный режим**: подходит для сценариев с интенсивными данными

## Опции отображения

- **Ширина страницы**: адаптивная или фиксированная
- **Контейнер карточек**: отображение содержимого в стиле карточек
- **Кнопка обновления**: быстрое обновление страницы
- **Кнопка сворачивания**: переключение раскрытия/сворачивания боковой панели
- **Кнопки верхней панели**: центр уведомлений, окно чата и т.д.

## Интернационализация

- **Многоязычность**: встроенный китайский и английский, легко расширяемый
- **Полный перевод**: системные настройки, меню, уведомления и т.д.
- **Динамическое переключение**: переключение языка без перезагрузки страницы

# Быстрый старт

## Требования к окружению

- Node.js ^22.18.0 или >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## Установка и использование

```bash
# Клонировать репозиторий
git clone git@github.com:any-tdf/raatdf.git

# Перейти в директорию проекта
cd raatdf

# Установить зависимости
bun install

# Запустить сервер разработки
bun run dev

# Собрать для продакшена
bun run build

# Предпросмотр продакшн-сборки
bun run preview
```

## Часто используемые команды

```bash
# Проверка и форматирование кода
bun run check  # Запустить проверку Vite+
bun run check:fix  # Автоматически исправить проблемы с кодом
bun run lint  # Проверить только стандарты кода
bun run lint:fix  # Автоматически исправить проблемы стандартов кода
bun run format  # Проверить форматирование кода
bun run format:fix  # Автоматически отформатировать код
```

# Вклад

Мы приветствуем все формы вклада, будь то новые функции, исправления ошибок или улучшения документации.

## Как внести вклад

1. Форкните этот репозиторий
2. Создайте свою ветку функции (`git checkout -b feature/AmazingFeature`)
3. Сделайте коммит ваших изменений (`git commit -m 'feat: add some amazing feature'`)
4. Отправьте в ветку (`git push origin feature/AmazingFeature`)
5. Откройте Pull Request

## Соглашение о коммитах

Пожалуйста, следуйте [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/):

- `feat`: новая функция
- `fix`: исправление ошибки
- `docs`: обновление документации
- `style`: изменение форматирования кода
- `refactor`: рефакторинг кода
- `chore`: изменение инструментов сборки или вспомогательных инструментов
