# Resumen del Proyecto

RAATDF es una plantilla de administración empresarial eficiente, elegante y ligera, construida con las tecnologías más recientes, proporcionando soluciones listas para usar.

# Enlaces Rápidos

📺 [Demo Online](https://raatdf.com) | 📖 [Documentación](https://doc.raatdf.com) | 🐙 [Repositorio GitHub](https://github.com/any-tdf/raatdf)

# Stack Tecnológico Principal

- **Herramienta de Construcción**: [Vite+](https://viteplus.dev) v0.2 (Vite 8) - Experiencia de desarrollo ultrarrápida
- **Framework Frontend**: [React](https://react.dev) v19 - Última versión, soporte para React Compiler
- **Sistema de Tipos**: [TypeScript](https://www.typescriptlang.org) v7 - Verificación de tipos estricta
- **Framework UI**: [Ant Design](https://ant.design) v6 - Biblioteca de componentes UI empresariales
- **Estilos**: [Tailwind CSS](https://tailwindcss.com) v4 - Framework CSS atómico
- **Gestión de Estado**: [Zustand](https://zustand-demo.pmnd.rs) v5 - Gestión de estado ligera
- **Enrutamiento**: [React Router](https://reactrouter.com) v7 - Solución de enrutamiento más reciente
- **Calidad de Código**: [Vite+](https://viteplus.dev) - Herramienta unificada de verificación y formateo de código

# Características

## Sistema de Layout

- **Múltiples Layouts**: Barra lateral, barra superior, layout mixto
- **Diseño Responsivo**: Compatibilidad perfecta con todos los tamaños de pantalla
- **UI Flotante**: Estilo de UI flotante elegante
- **Modo Inmersivo**: Experiencia de pantalla completa centrada en contenido
- **Herramientas Laterales**: Colocar barra de herramientas en la parte inferior de la barra lateral (solo layout vertical)

## Sistema de Temas

- **Tema Claro/Oscuro**: Tres modos: claro, oscuro y seguir sistema
- **Colores del Tema**: 10+ colores preestablecidos + colores personalizados
- **Cambio Dinámico**: Transición de tema sin interrupciones mediante variables CSS
- **Tamaño de Borde Redondeado**: 9 tamaños de borde redondeado seleccionables (0-24px)

## Mejoras de Interacción

- **Múltiples Pestañas**: Máximo 16 pestañas, cerrar automáticamente la más antigua
- **Caché de Páginas**: Mantener estado de la página, mejorar experiencia del usuario
- **Estilos de Pestañas**: 4 estilos: predeterminado, botón, simple, apilado
- **Animaciones de Transición: Efectos de animación variados como deslizamiento, fadeIn, escala
- **Modo Compacto**: Adecuado para escenarios intensivos en datos

## Opciones de Visualización

- **Ancho de Página**: Adaptativo o ancho fijo
- **Contenedor de Tarjetas**: Visualización de contenido estilo tarjeta
- **Botón de Actualizar**: Actualización rápida de página
- **Botón de Contraer**: Alternar expansión/contracción de barra lateral
- **Botones de Barra Superior**: Centro de notificaciones, ventana de chat, etc.

## Internacionalización

- **Múltiples Idiomas**: Chino e inglés integrados, fácil de extender
- **Traducción Completa**: Configuración del sistema, menús, notificaciones, etc.
- **Cambio Dinámico**: Cambiar idioma sin necesidad de recargar página

# Inicio Rápido

## Requisitos del Entorno

- Node.js ^22.18.0 o >= 24.11.0
- Bun >= 1.3.14
- Vite Plus 0.2.6

## Instalación y Uso

```bash
# Clonar repositorio
git clone git@github.com:any-tdf/raatdf.git

# Entrar al directorio del proyecto
cd raatdf

# Instalar dependencias
bun install

# Iniciar servidor de desarrollo
bun run dev

# Construir para producción
bun run build

# Previsualizar construcción de producción
bun run preview
```

## Comandos Comunes

```bash
# Verificación y formateo de código
bun run check  # Ejecutar verificación Vite+
bun run check:fix  # Corregir automáticamente problemas de código
bun run lint  # Verificar solo normas de código
bun run lint:fix  # Corregir automáticamente problemas de normas de código
bun run format  # Verificar formato de código
bun run format:fix  # Formatear código automáticamente
```

# Contribuir

Bienvenimos todas las formas de contribución, ya sean nuevas características, correcciones de errores o mejoras de documentación.

## Cómo Contribuir

1. Fork este repositorio
2. Crear su rama de característica (`git checkout -b feature/AmazingFeature`)
3. Commit sus cambios (`git commit -m 'feat: add some amazing feature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abrir un Pull Request

## Convenciones de Commit

Por favor siga [Conventional Commits](https://www.conventionalcommits.org/es/v1.0.0/):

- `feat`: Nueva característica
- `fix`: Corrección de error
- `docs`: Actualización de documentación
- `style`: Cambio de formato de código
- `refactor`: Refactorización de código
- `chore`: Cambio en herramientas de construcción o herramientas auxiliares
